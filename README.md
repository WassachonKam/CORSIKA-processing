# CORSIKA Processing Pipeline

This repository contains scripts and notebooks for organizing, decoding, and plotting simulation data.  
All simulation folders share the same subdirectory structure: `.../particle/energy/angle/`



## Folder Description
 
1. **/Particles**  
   Stores particle number files generated by `corsikaReader.cpp`. 
   Run by either `make` and `./corsikaReader.cpp proton lgE_16.0 0.0 --thinned` or  `job_corsika.sub` with `params_corsika.txt`

2. **/radEnergy**  
   Stores radiation energy of every run in each energy/zenith angle. 
   /radEnergy/raw: unnormalized radiation energy from submit_RadiationEnergy.py
   /radEnergy/norm_sintheta2: normalized radiation energy from submit_norm_RadiationEnergy.py

## File Description

**submit_** and **job_** files are for mass running in npx HTCondor

1. radiation energy: `submit_RadiationEnergy.py` --> output stored in /radEnergy/raw
2. radiation energy normalization: `submit_norm_RadiationEnergy.py` --> output stored in /radEnergy/norm_sintheta2
3. plot radiation energy every primary particle bins: `submit_RadiationEnergyPlot.py` --> output stored in /figure/RadiationEnergy
4. get number of particles at ground and zenith angle of each shower: `submit_GroundParticles.py` --> output stored in /GroundTotalParticles
5. get Xmax and number of particles at Xmax: `submit_Xmax_ParseAndFitLongitudinalProfile.py` --> prerequisite zenith from /GroundTotalParticles --> store output in /Xmax 
6. calculate deposited energy inside the scintillator panels: `submit_ScintillatorResponse.py` --> output stored in /TotalEdepScint

run in npx: 
ssh npx-submitter
condor_submit job_[task].sub
